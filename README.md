# CrystalCraft

CrystalCraft 是一款在线晶体结构可视化与编辑工具，可直接在浏览器中导入结构、调整显示效果并导出图片。

## 在线使用

[打开 CrystalCraft](https://niananruo.github.io/CrystalCraft/)

## 主要功能

- **结构导入与导出**：支持 POSCAR/CONTCAR、CIF、XYZ 文件导入，以及 POSCAR、CIF、XYZ 格式导出。
- **三维可视化**：提供球棍、空间填充、纯棍、线框模型和 31 种材质，支持光照、阴影、轮廓、原子标签与自动旋转。
- **化学键与多面体**：支持 VESTA 风格 Bonds 编辑，可按元素或位点标签设置键长范围、搜索模式和周期边界补全，并显示配位多面体与氢键。
- **原子与晶胞编辑**：支持原子增删、元素替换、颜色与半径调整，以及超胞构建、晶胞变换、原点平移和真空层设置。
- **观察与测量**：支持晶胞及周期边界显示、晶轴方向切换、距离与夹角测量。
- **体数据展示**：支持 CHGCAR、CHGDIFF、LOCPOT、ELFCAR，提供等值面、正负双等值面、二维切片与切片数据导出。
- **图片导出**：支持高清 PNG、透明背景、自定义画幅，以及最高 8K 分辨率选项。
- **项目保存与恢复**：支持项目文件保存、本机自动保存、恢复，以及编辑撤销与重做。
