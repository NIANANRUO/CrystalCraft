# 15 种新增渲染模式：评估与接入

这些模式增加在原有 20 种材质之后，总计 35 种；旧 ID、材质实现和项目选择保留。侧栏“材质预设”和 Objects 菜单共用分类目录，原有三组保留，新增以下四组。入口提供性能成本、数据要求和适用边界。

## 逐项评估

| 原建议 | 适配当前网页后的实现 | 用途与边界 | 成本 |
|---|---|---|---|
| 琥珀树脂 | 暖金吸收、IOR 1.55、清漆与实时透射 | 作用于原子/键，不额外生成包住整块结构的树脂容器 | 高 |
| 哑光肤感硅胶 | 粗糙度 0.95、低镜面强度、柔和 sheen | 保留元素色；柔性材料与聚合物示意，未做次表面随机游走 | 中 |
| 金缮黑陶 | 黑陶底、程序金纹、裂纹处独立金属度/粗糙度 | 装饰裂纹；不由缺陷、应力或真实晶界计算 | 中 |
| 湿画水彩 | 浅颜料、边缘积墨、物体空间固定纸纤维 | 教学与机制示意；不是流体/纸张渗流模拟 | 低 |
| SEM 喷金 | 改称 SEM 边缘灰度：漫反射、边缘增亮和微颗粒 | 二次电子视觉近似；不声称模拟喷镀厚度或真实实验图像 | 低 |
| HAADF-STEM | 已知元素 Z^1.7 相对亮度、柔化斑点与暗背景 | 以当前结构最大 Z 归一化；未知元素中性灰。不含厚度、占据、探针、热散射/多重散射模型 | 低～中 |
| HRTEM 相衬 | 灰底暗斑和弱环纹 | 仅视觉示意，未计算传播波、离焦、球差、CTF，不能据此确认晶带轴 | 低 |
| AFM 地形 | 改称 AFM Palette / Z 高度映射：Viridis 按原子笛卡尔 Z 着色 | 使用真实坐标（Å）；无探针卷积、扫描反馈或表面重建 | 低 |
| ESP 热图 | CSV 电势原子采样，负红/零白/正蓝，零中心自动范围 | 不把部分电荷或 LOCPOT 自动当作分子 ESP；未构建分子溶剂可及表面 | 低 |
| 轨道相位 | CSV 实值波函数原子采样，负蓝/正橙/零灰，幅度控制亮度/透明度 | 不支持复波函数连续相位，不从 ELF 或差分电荷推导波函数，不伪造波节面或 HOMO/LUMO 体轨道 | 低 |
| 自旋极化 | CSV 有符号自旋标量，负青/正金/零灰与边缘微晕 | 单位 μB；不猜测磁序，不代表非共线自旋向量方向 | 低 |
| B-factor 热动 | CIF 的 Cartesian U 张量转换等效 B，或显式 CSV B-factor，Ironbow 色阶 | B=8π²Tr(U_cart)/3（Å²）；B-factor 不等于温度，不证明脱附倾向 | 低 |
| 霓虹经纬网 | 物体空间经纬线着色和亮键、暗背景 | 静态程序纹理，不增加持续动画；可继续使用现有自动旋转 | 低 |
| LiDAR 点云 | 固定程序点阵与柔化点边，保留球体拾取 | 视觉点云，不生成数千独立 Mesh/原子，也不声称来自激光或衍射测量 | 低 |
| 极地冰裂 | 冷色 IOR 1.31 透射、清漆、程序裂隙 | 实时近似；未做路径追踪的多次内反射、体内气泡或真实冰相计算 | 高 |

琥珀/冰晶保留原有环境光照，但透射无法达到 Cycles/Octane 的离线路径追踪效果。大结构可选择低成本模式；现有不透明实例化仍适用，透明/透射保持逐物体排序。新增模式不重写旧材质的高光、颜色或渲染代码；自身高光优先于原子通用 Phong 高光覆盖。

HAADF/HRTEM 为了呈现原子斑点，会在该模式中临时不绘制化学键/氢键；切换回其他模式恢复。原有材质入口、结构数据与键配置没有删除。

## 数据着色流程

选择 ESP、Orbital Phase、Spin 或 B-factor 后，在材质说明中导入最多 1 MiB 的 CSV。首列必须为 `atom_id`，匹配当前结构原子 ID。其余列可选：

| 列 | 解释 | 单位 |
|---|---|---|
| esp_V | 用户计算提供的电势原子采样 | V |
| orbital_amplitude | 用户计算提供的有符号波函数原子采样 | a.u.，沿用上游归一化 |
| spin_muB | 用户提供的有符号磁矩标量 | μB |
| b_factor_A2 | 用户提供的非负 B-factor | Å² |

```csv
atom_id,esp_V,orbital_amplitude,spin_muB,b_factor_A2
1,-0.3,0.2,1,0.8
2,0.3,-0.2,-1,1.2
```

这只是格式示例，网页不会自动将示例写入真实结构。支持部分原子覆盖和空值；未知/重复 ID、未知列、不完整数值、NaN/Infinity 和负 B-factor 会拒绝，保留旧数据。新 CSV 替换上一份标量集，避免省略原子仍残留旧数据。原子数据、来源文件名和选中的模式随项目保存、撤销和恢复。

缺少对应数据时为中性灰，界面与 PNG 均明确说明。图例显示覆盖率、基结构范围和单位，数据映射只控制原子颜色，键为中性连接色。原子自身数据不会随着坐标编辑重新计算；更换结构后应重新提供与其匹配的标量，超胞复制沿用源位点数据。周期边界副本使用源位点着色，AFM 色标同样以基结构为范围。

B-factor 优先使用显式 CSV 值，否则从当前 CIF 位移张量取得等效值。AFM 直接使用当前基结构笛卡尔 Z，不需要 CSV。所有有符号范围以零为中心；相位、自旋的正/负分别着色，零值为灰。选中原子采用边缘标记，保留数据颜色主体。

新增模式的 PNG 自动附带模式名称与“视觉近似/艺术表现/数据范围”说明；数据模式附来源与单位。暗背景模式的普通 PNG 保留暗背景，透明导出保留 Alpha；原有 20 种模式的导出不增加这些说明。

## 验证与来源

单元测试检查原 20 个 ID 保留、35 个唯一入口、光学参数、CSV 严格绑定、Z 权重、等效 B 和项目回读。浏览器使用固定的六原子合成 QA 模型逐一编译/截图，另用显式标记的已知 CSV 检查实际着色、失败保留、项目恢复和 PNG；这些视觉样例不代表计算结果。截图和记录位于 `docs/qa/materials/`。

物理材质支持与实时成本参考 [Three.js MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)（以本项目锁定版本实际支持的属性为准）。HRTEM 所需传播和 CTF 流程参考 [abTEM HRTEM quickstart](https://abtem.github.io/doc/user_guide/examples/notebooks/hrtem_quickstart.html)。位移参数定义参考 [IUCr B_iso_or_equiv](https://www.iucr.org/__data/iucr/cifdic_html/1/cif_core.dic/Iatom_site_B_iso_or_equiv.html)。这些来源支持功能边界，不构成期刊、工作室或软件厂商对本网页的认可。
