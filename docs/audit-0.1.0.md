# CrystalCraft 对抗性审核与加固记录

审核目标：在不删除现有功能或板块的前提下，提高 GitHub Pages 部署可靠性、结构数据正确性和浏览器运行稳定性。复核日期：2026-10-19。

结论：已完成本地一轮实质加固。项目具备静态部署配置和可重复验证入口，但尚未建立远程 GitHub 仓库、实际发布 Pages，也没有覆盖所有浏览器/GPU。不能把一次本地回归解释为“任何文件、任何设备都稳定”。

## 已确认问题与本轮处理

## 仍需巩固的事项（按建议顺序）

1. **P1 · 完成真实部署验收。** 当前目录不是 Git 仓库、没有远程 URL。所有者建立仓库、选择 Pages 的 GitHub Actions 来源并首次发布后，应在实际 HTTPS 地址复查加载/导入/下载、Actions 权限、发布回滚。操作步骤见 README。本轮未对外上传源码或结构数据。
2. **P2 · 处理开发链漏洞。** Tailwind 3 间接依赖的 `braces <=3.0.3` 有递归耗尽问题，当前公告无修复版；`postcss-selector-parser <7.1.6` 有解析复杂度问题。本轮保留现有样式体系，未进行会影响全站 CSS 的 Tailwind 4 大版本迁移。后续应在独立分支升级构建链并对全站截图/样式回归；同时只构建可信源码，开发服务器默认绑定本机。来源：[braces 公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)、[PostCSS selector 公告](https://github.com/advisories/GHSA-rj75-hqrm-r3gf)。这些依赖不进入发布后的运行时包，但会影响开发/构建环境，不能宣称整个依赖树已无漏洞。
3. **P2 · 完成原本尚未接入的参数。** Atoms 的 Specular/Shininess、Stacks/Slices、热位移椭球、隐藏孤立原子、Radii type、标签 Offset，以及真实 Outline width 尚未完整连接渲染。现有控件与板块全部保留并明确提示。Isosurfaces/Sections 本来就是未来 CHGCAR/LOCPOT/ELFCAR 的占位页，仍保留；本轮没有把它们伪装为可用体绘制。
4. **P2 · 持久化与恢复。** 属性窗口有局部撤销，但尚无全局多步撤销/重做、项目文件与自动恢复。刷新仍会丢失未导出结构与视觉编辑。建议下一阶段增加带版本号的项目存档，再增加自动保存和历史记录。
5. **P2 · 大模型与跨设备性能。** 仍以逐原子 Mesh 渲染，部分配位/氢键处理仍与邻域规模相关。已加入缓存、空间索引和预算，但建议后续用 InstancedMesh、Worker 解析、渐进加载，并针对 500/1,000/2,000 原子、透明材质/阴影/标签组合做真实桌面与移动设备长时间测量。
6. **P2 · 科学语义覆盖。** 当前 CIF 导出保留原子、坐标、占据率并写 P1，不完整保留原始空间群/文献/无序元数据；非 P1 缺显式操作表时拒绝导入。化学键与氢键属于阈值推断。多帧轨迹、磁性 CIF、任意晶体学设置与电子密度数据需要专业格式库和参考样例进一步比对。
7. **P3 · 复用授权和维护约定。** 原项目没有所有者指定的开源许可证，需由所有者选择。第三方库及 spglib 静态数据的许可文本已加入随站点分发的 `public/THIRD_PARTY_NOTICES.txt`。帮助菜单已统一读取 package 版本，后续仍需建立变更日志、发布标签和维护负责人约定。

## 功能保留核对

保留 File/Edit/View/Objects/Utilities/Help 菜单、工具栏、左侧 Style/Tools/Objects、底部 Output/Summary/Comment、Properties 全部标签、周期表、晶胞变换、渲染导出窗口；保留全部 20 材质和原有图像分辨率选项。旧源码组件、历史截图和临时脚本没有删除，仅通过 `.gitignore` 排除不必发布的本地产物。

安全预算和严格格式检查会拒绝原本可能卡死浏览器或静默生成错误结果的输入。它们保留正常能力，并使不支持或超预算的操作可解释、可恢复；不以删减板块来规避问题。
